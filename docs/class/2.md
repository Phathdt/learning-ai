"Masterclass AgentOps:
Deploy, Operate and Continuously Improve AI Agents
"
"Khóa học hướng dẫn đưa một AI agent từ môi trường phát triển lên thành sản phẩm có thể triển khai, theo dõi và cải thiện liên tục trên môi trường thực tế.

Học viên thực hành toàn bộ vòng đời AgentOps: chuẩn hóa project, cung cấp agent qua API, đóng gói bằng Docker, triển khai lên cloud, tự động hóa CI/CD, xây dựng observability và continuous evaluation, tối ưu cost/latency, vận hành tác vụ dài và ứng phó sự cố production.

Khóa học tập trung vào những khó khăn xuất hiện khi vận hành agent: môi trường không đồng nhất, thay đổi khó kiểm soát, thiếu dữ liệu để điều tra lỗi, khó đánh giá và duy trì chất lượng, chi phí tăng, latency cao và tác vụ dài bị gián đoạn. Hệ thống được thiết kế để phục vụ nhiều người dùng và có thể theo dõi chất lượng, hiệu năng, mức sử dụng theo từng nhóm."
"🎯Course Information:
• Thời lượng: 10 buổi × 2 giờ.
• Đối tượng: AI Engineer, Software Engineer hoặc Platform Engineer muốn triển khai và vận hành agent trên môi trường thực tế.
• Đầu vào: hoàn thành khóa Agent Engineering hoặc đã có kiến thức cơ bản về agent, Python và API.
• Starter project: cung cấp agent mẫu để học viên có thể ôn tập và tham gia khóa độc lập.
• Phân bổ gợi ý: 45–60 phút lý thuyết và demo; thời gian còn lại dành cho thực hành và review.
• Đầu ra: một agent chạy trên cloud với CI/CD, observability, continuous evaluation, cost/latency monitoring, durable task workflow và production runbook.

🎯Learning Journey:
• Prepare → Serve → Containerize → Deploy → Automate → Observe → Evaluate → Optimize → Run Durably → Operate"
Buổi 1 (Thứ 4, 18.11) Theory Lab
"AgentOps: From Prototype to Production
" "- Vòng đời một sản phẩm agent từ development đến production.

- Sự khác biệt giữa MLOps và AgentOps.
- Cấu trúc project, dependency management và cấu hình môi trường.
- Git/GitHub workflow và cách quản lý các phiên bản release.
- Versioning cho code và các thành phần quan trọng của agent." "Chuẩn hóa agent project thành repository có cấu trúc, cấu hình theo môi trường và phiên bản baseline có thể tái lập.
  "
  Buổi 2 (Thứ 6, 20.11) Theory Lab
  Serving an Agent with FastAPI "- Ôn tập agent harness ở mức cần thiết cho vận hành.
- Xây dựng Agent API bằng FastAPI.
- SSE streaming để truyền tiến độ, tool activity và kết quả về giao diện người dùng.
- User/session metadata, data isolation, error handling, health check và application logs cơ bản.
  " "Đưa starter agent thành FastAPI service, kết nối giao diện qua SSE và bổ sung health check cùng logs cơ bản.
  "
  Buổi 3 (Thứ 4, 25.11) Theory Lab
  Containerizing Agents with Docker "- Image, container, registry và container lifecycle.
- Dockerfile, build cache, dependency pinning và tối ưu image.
- Environment variables, secrets, networking và persistent data.
- Health check, graceful shutdown và tính nhất quán giữa local–production." "Đóng gói Agent API bằng Docker và chạy toàn bộ agent cùng các dependencies qua Docker Compose.
  "
  Buổi 4 (Thứ 6, 27.11) Theory Lab
  Deploying an Agent to Cloud "- Kiến trúc cloud cơ bản cho Agent API và các dịch vụ liên quan.
- Cấu hình runtime, secrets, identity và access control.
- Scaling, logs, persistent data, quản lý phiên bản triển khai, rollback và kiểm soát chi phí." "Triển khai containerized Agent API lên Google Cloud Run, cấu hình các thành phần cần thiết và có thể truy cập qua URL công khai.
  "
  Buổi 5 (Thứ 4, 02.12) Theory Lab
  CI/CD with GitHub Actions "- Continuous Integration, Continuous Delivery và release workflow.
- Cách GitHub Actions tự động kiểm tra, đóng gói và triển khai ứng dụng.
- Unit test và kiểm thử tự động cho code, Agent API cùng các hành vi quan trọng của agent.
- Quản lý phiên bản triển khai, môi trường release và rollback." Xây CI/CD workflow để tự động kiểm tra và triển khai một phiên bản Agent API từ repository lên môi trường cloud
  Buổi 6 (Thứ 6, 04.12) Theory Lab
  Observability for Agent Systems "- Logs, metrics và traces trong một agent system.
- Structured logging và correlation giữa API logs với agent traces.
- Langfuse tracing cho agent execution, quality, cost và latency.
- OpenTelemetry và Grafana cho application/service monitoring.
- Dashboard, alert và quy trình điều tra một request lỗi.
  " "Instrument Agent API bằng Langfuse và OpenTelemetry; hoàn thiện dashboard từ template và truy ngược một request lỗi từ service log đến agent trace.

"
Buổi 7 (Thứ 4, 09.12) Theory Lab
Continuous Evaluation with Langfuse "- AI Engineering Loop và vòng đời cải thiện chất lượng agent.

- Offline evaluation trước release và online evaluation trên production traces.
- Xây regression dataset từ feedback và failure cases.
- Code evaluator, LLM-as-a-judge, human review và quality gate.
- So sánh thay đổi với baseline trước khi release." Tạo regression dataset nhỏ trên Langfuse, chạy experiment so sánh baseline/candidate và đưa một quality gate vào release workflow.
  Buổi 8 (Thứ 6, 11.12) Theory Lab
  Optimizing Cost and Latency "- Đo cost, token usage và latency theo model, feature, user và release.
- Phân tích bottleneck trong model, context, tools và agent loop.
- Tối ưu ở application layer: lựa chọn model, quản lý context, caching, tool calls và parallel execution.
- AI Gateway cho routing, load balancing, rate limiting và kiểm soát usage.
- Cân bằng cost, latency và quality khi phục vụ nhiều người dùng." "Dùng Langfuse xác định một bottleneck, tối ưu agent ở application layer, áp dụng cấu hình AI Gateway phù hợp và so sánh cost, latency, quality trước–sau.
  "
  Buổi 9 (Thứ 4, 16.12) Theory Lab
  "Durable Execution and High Throughput for Long-Horizon Agents
  " "- Khi nào agent cần chạy nền thay vì phụ thuộc vào kết nối với người dùng.
- Kiến trúc Agent API, message queue, worker, state và checkpoint.
- Task lifecycle, progress tracking, retry và error recovery.
- Cancel, resume, idempotency và xử lý nhiều tác vụ đồng thời." Nâng cấp Agent API sử dụng queue/worker; gửi task, thoát ứng dụng rồi theo dõi tiến độ và test phục hồi tác vụ khi worker bị gián đoạn.
  Buổi 10 (Thứ 6, 18.12) Theory Lab
  Production Game Day and Final Project "- Production readiness và release checklist.
- Release approval, rollback và xác minh sau triển khai.
- Incident response và cải thiện sau sự cố.
- Operations ownership và production runbook." "Triển khai phiên bản agent cuối, xử lý một failure scenario bằng logs, traces và eval results; phục hồi hệ thống và hoàn thiện production runbook.
  "

  • Docker, Docker Compose và Artifact Registry.
  • Google Cloud Run, Secret Manager và Cloud IAM.
  • Langfuse cho tracing, evaluation, cost và latency.
