## 1. Theory — API Architecture (20 phút)

### 1.1 Tại sao cần API cho agent

Ở Buổi 1–8, agent chỉ chạy local, synchronous, single-user CLI:

```python
result = agent.run(task="...")  # Chặn cho đến khi xong
print(result)
```

Production agent cần:

- **Multi-user**: nhiều user cùng lúc gọi agent, tách session.
- **Streaming**: real-time feedback thay vì chặn 5 phút.
- **Stateless API server**: có thể scale horizontal, restart không mất data.
- **Auth**: JWT hoặc OAuth, per-tenant isolation.
- **Observability**: mỗi request có request_id, correlate logs.
- **Reliability**: timeout, cancellation, retry.

API là điểm giao tiếp giữa client (web UI, mobile, CLI) và agent harness.

### 1.2 API layering

```text
Client (Browser, Mobile, CLI)
  ↓ HTTPS / SSE
┌──────────────────────────────────────┐
│ FastAPI / Middleware                 │
│ ├─ Auth (JWT verify)                 │

│ └─ Request ID / Correlation          │
└──────────┬───────────────────────────┘
           ↓
┌──────────────────────────────────────┐
│ Endpoint Layer                       │
│ ├─ /agent/run (sync)                 │
│ ├─ /agent/stream (SSE)               │

│ └─ /health, /readiness               │
└──────────┬───────────────────────────┘
           ↓
┌──────────────────────────────────────┐

```

### 1.3 API contract

**Request schema**:

```python
class AgentRunRequest(BaseModel):
    task: str                          # User query
    session_id: str | None = None      # Nếu None → tạo session mới
    model_config = ConfigDict(examples=[{
        "task": "Vì sao doanh thu tháng 9 giảm?",

```

**Response schema (sync)**:

```python
class AgentRunResponse(BaseModel):
    run_id: str                        # Unique run ID
    session_id: str                    # Session ID
    status: Literal["success", "failed", "timeout"]
    result: str                        # Final answer
    tool_calls: int                    # Số lần gọi tool
    duration_ms: int                   # Thời gian thực thi
    error: str | None = None           # Lỗi nếu failed
```

**Streaming event (SSE)**:

```python
class AgentEvent(BaseModel):
    event_type: Literal[
        "agent.started",
        "agent.thinking",
        "tool.started",
        "tool.completed",
        "agent.progress",
        "agent.completed",
        "agent.failed"
```

**Error schema**:

```python
class ErrorResponse(BaseModel):

    request_id: str  # Để correlate logs

```

### 1.4 SSE (Server-Sent Events)

SSE là HTTP streaming: server gửi events cho client qua single connection.

**Ưu điểm vs WebSocket**:

- Đơn giản: dùng HTTP/1.1 thôi, không cần upgrade.
- Auto-reconnect: browser tự reconnect nếu drop.
- Backward-compatible: mọi HTTP client support.

**Nhược điểm**:

- Unidirectional: client không gửi message được khi streaming.
- Browser: max 6 concurrent SSE connection mặc định.

**Event format**:

```
data: {"event_type": "agent.started", "run_id": "run_123"}
data: {"event_type": "agent.thinking", "data": {"thoughts": "..."}}
data: {"event_type": "tool.started", "data": {"tool_name": "query_db"}}
```

## 2. Deep dive — Session, Auth, Streaming (30 phút)

### 2.1 Session design

Session = conversation state + user context.

```python
class SessionMetadata(BaseModel):
    session_id: str
    user_id: str
    tenant_id: str
    created_at: float
    last_accessed: float
    conversation: list[dict]  # LLM messages
    context: dict  # System context, skills, memory
```

**Session lifecycle**:

```text
/agent/run?session_id=<id>
  ↓
Server kiểm tra DB
  ├─ Tồn tại → Load context từ DB
  └─ Không tồn tại → Tạo session mới
  ↓
Agent chạy
  ↓
Append messages → Save vào DB
  ↓
Response return session_id để client reuse
```

**Multi-turn conversation**:

```python
# Turn 1
POST /agent/run
  body: {"task": "doanh thu tháng 9", "session_id": None}
  response: {"session_id": "sess_123", ...}

# Turn 2 (client gửi session_id)
POST /agent/run
  body: {"task": "so sánh với tháng 8", "session_id": "sess_123"}
  # Agent có context từ turn 1
  response: {"session_id": "sess_123", ...}
```

### 2.2 Authentication and authorization

**Multi-tenant isolation**:

```python
@app.post("/agent/run")
async def agent_run(req: AgentRunRequest, token: str = Header(...)):
    # 1. Verify JWT token
    payload = verify_jwt(token)
    user_id = payload["user_id"]
    tenant_id = payload["tenant_id"]

    # 2. Check session ownership
    if req.session_id:
        session = await db.get_session(req.session_id)
        if session.tenant_id != tenant_id:
            raise HTTPException(403, "Unauthorized")

    # 3. Run agent với tenant context
    result = await agent.run(req.task, tenant_id=tenant_id)
    return result
```

**Tool permission per tenant**:

```python
# Agent chỉ có quyền gọi tool mà tenant cho phép

```

### 2.3 Streaming pattern

**EventEmitter trong agent loop**:

```python
class AgentEventEmitter:
    def __init__(self):
        self.subscribers = []

    def emit(self, event: AgentEvent):
        for sub in self.subscribers:
            sub(event)

    def subscribe(self, callback):
        self.subscribers.append(callback)

# Trong agent loop
emitter.emit(AgentEvent(
    event_type="tool.started",
    data={"tool_name": "query_db", "input": {...}}
))
```

**FastAPI SSE endpoint**:

```python
@app.post("/agent/stream")
async def agent_stream(req: AgentRunRequest):
    async def event_generator():
        queue = asyncio.Queue()

        def emit_event(event: AgentEvent):
            await queue.put(event)

        # Start agent in background
        agent_task = asyncio.create_task(
            agent.run_async(req.task, emit_event)
        )

        # Yield events as they come
        while True:
            try:
                event = await asyncio.wait_for(queue.get(), timeout=30)
                yield f"data: {json.dumps(event.dict())}\n\n"
            except asyncio.TimeoutError:
                yield "event: ping\ndata: {}\n\n"  # Keep-alive
            except asyncio.CancelledError:
                break

    return StreamingResponse(
        event_generator(),
        media_type="text/event-stream"
    )
```

### 2.4 Reliability patterns

**Timeout**:

```python
@app.post("/agent/run")
async def agent_run(req: AgentRunRequest, timeout: int = 120):
    try:
        result = await asyncio.wait_for(
            agent.run_async(req.task),
            timeout=timeout
        )
    except asyncio.TimeoutError:
        return {"status": "timeout", "error": "Agent exceeded 120s"}
```

**Graceful shutdown**:

```python
@app.on_event("shutdown")
async def shutdown():
    # Cancel pending agent runs
    for task in all_running_tasks:
        task.cancel()
    await asyncio.gather(*all_running_tasks, return_exceptions=True)
```

**Error handling**:

```python
@app.exception_handler(Exception)
async def exception_handler(request: Request, exc: Exception):
    request_id = request.scope.get("request_id", "unknown")
    logger.error(f"Unhandled error", extra={
        "request_id": request_id,
        "error": str(exc)
    })
    return JSONResponse(
        {"error": "Internal server error", "request_id": request_id},
        status_code=500
    )
```

**Session store** (`session_store.py`):

```python
import json
from datetime import datetime

class SessionStore:
    def __init__(self, db_path: str = "sessions.json"):
        self.db_path = db_path

    async def save_session(self, session_id: str, user_id: str,
                          tenant_id: str, messages: list):
        data = {
            "session_id": session_id,
            "user_id": user_id,
            "tenant_id": tenant_id,
            "messages": messages,
            "created_at": datetime.now().isoformat()
        }
        # In production: use PostgreSQL
        with open(self.db_path, "w") as f:
            json.dump(data, f)

    async def get_session(self, session_id: str, user_id: str, tenant_id: str):
        try:
            with open(self.db_path) as f:
                data = json.load(f)
                if data["session_id"] == session_id and \
                   data["user_id"] == user_id and \
                   data["tenant_id"] == tenant_id:
                    return data
        except:
            pass
        return None
```

**Main app** (`app.py`):

```python
import asyncio
import json
import uuid
import logging
from datetime import datetime
from contextlib import asynccontextmanager

from fastapi import FastAPI, Header, HTTPException, Request
from fastapi.responses import StreamingResponse
from pydantic import BaseModel

from schemas import AgentRunRequest, AgentEvent
from session_store import SessionStore

# Setup logging
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

session_store = SessionStore()

# Middleware: correlation ID
@app.middleware("http")
async def add_correlation_id(request: Request, call_next):
    request_id = str(uuid.uuid4())
    request.scope["request_id"] = request_id
    response = await call_next(request)
    response.headers["X-Request-ID"] = request_id
    return response

@app.post("/agent/run")
async def agent_run(
    req: AgentRunRequest,
    authorization: str = Header(None),
    request: Request = None
):
    """Synchronous agent execution"""
    request_id = request.scope.get("request_id")

    # Mock auth
    user_id = "user_123"
    tenant_id = "tenant_456"

    # Session handling
    if not req.session_id:
        req.session_id = f"sess_{uuid.uuid4().hex[:12]}"
    else:
        session = await session_store.get_session(
            req.session_id, user_id, tenant_id
        )
        if not session:
            raise HTTPException(403, "Session not found or unauthorized")

    logger.info(f"Agent run started", extra={
        "request_id": request_id,
        "session_id": req.session_id,
        "user_id": user_id,
        "task": req.task[:50]
    })

    # Simulate agent execution
    try:
        result = await asyncio.wait_for(
            simulate_agent_task(req.task),
            timeout=120
        )
    except asyncio.TimeoutError:
        logger.error("Agent timeout", extra={
            "request_id": request_id,
            "session_id": req.session_id
        })
        raise HTTPException(504, "Agent timeout")

    # Save session
    await session_store.save_session(
        req.session_id, user_id, tenant_id,
        [{"role": "user", "content": req.task},
         {"role": "assistant", "content": result}]
    )

    return {
        "session_id": req.session_id,
        "status": "success",
        "result": result,
        "request_id": request_id
    }

@app.post("/agent/stream")
async def agent_stream(
    req: AgentRunRequest,
    authorization: str = Header(None),
    request: Request = None
):
    """Streaming agent execution via SSE"""
    request_id = request.scope.get("request_id")
    run_id = f"run_{uuid.uuid4().hex[:12]}"
    user_id = "user_123"
    tenant_id = "tenant_456"

    if not req.session_id:
        req.session_id = f"sess_{uuid.uuid4().hex[:12]}"

    logger.info(f"Agent stream started", extra={
        "request_id": request_id,
        "run_id": run_id,
        "session_id": req.session_id
    })

    async def event_generator():
        try:
            # Event 1: started
            yield f"data: {json.dumps({'event_type': 'agent.started', 'run_id': run_id, 'timestamp': datetime.now().timestamp()})}\n\n"
            await asyncio.sleep(0.1)

            # Event 2: thinking
            yield f"data: {json.dumps({'event_type': 'agent.thinking', 'run_id': run_id, 'data': {'thoughts': 'Analyzing task...'}, 'timestamp': datetime.now().timestamp()})}\n\n"
            await asyncio.sleep(0.5)

            # Event 3: tool.started
            yield f"data: {json.dumps({'event_type': 'tool.started', 'run_id': run_id, 'data': {'tool_name': 'query_db'}, 'timestamp': datetime.now().timestamp()})}\n\n"
            await asyncio.sleep(0.3)

            # Event 4: tool.completed
            yield f"data: {json.dumps({'event_type': 'tool.completed', 'run_id': run_id, 'data': {'tool_name': 'query_db', 'result': 'Data retrieved'}, 'timestamp': datetime.now().timestamp()})}\n\n"
            await asyncio.sleep(0.1)

            # Event 5: agent.progress
            yield f"data: {json.dumps({'event_type': 'agent.progress', 'run_id': run_id, 'data': {'progress': 50}, 'timestamp': datetime.now().timestamp()})}\n\n"
            await asyncio.sleep(0.2)

            # Event 6: completed
            result = "Task completed successfully"
            yield f"data: {json.dumps({'event_type': 'agent.completed', 'run_id': run_id, 'data': {'result': result}, 'timestamp': datetime.now().timestamp()})}\n\n"

            logger.info("Agent stream completed", extra={
                "request_id": request_id,
                "run_id": run_id
            })

        except asyncio.CancelledError:
            logger.warning("Stream cancelled", extra={
                "request_id": request_id,
                "run_id": run_id
            })
            yield f"data: {json.dumps({'event_type': 'agent.failed', 'run_id': run_id, 'data': {'error': 'Cancelled'}})}\n\n"

    return StreamingResponse(
        event_generator(),
        media_type="text/event-stream",
        headers={"X-Request-ID": request_id}
    )

@app.get("/health")
async def health():
    """Liveness probe"""
    return {"status": "ok"}

@app.get("/readiness")
async def readiness():
    """Readiness probe"""
    try:
        # Check dependencies
        await session_store.get_session("dummy", "dummy", "dummy")
        return {"status": "ready"}
    except:
        return {"status": "not_ready"}, 503

@app.get("/sessions/{session_id}")
async def get_session(session_id: str, user_id: str = Header(...), tenant_id: str = Header(...)):
    """Get session context"""
    session = await session_store.get_session(session_id, user_id, tenant_id)
    if not session:
        raise HTTPException(404, "Session not found")
    return session

async def simulate_agent_task(task: str):
    """Simulate agent task for demo"""
    await asyncio.sleep(1)
    return f"Answer to '{task}': Processed successfully"

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

## 5. Failure modes & recovery

| Failure              | Symptom                      | Recovery                              |
| -------------------- | ---------------------------- | ------------------------------------- |
| Connection drop      | SSE stream sudden close      | Browser auto-reconnect, client store  |
|                      |                              | run_id and poll `/sessions/{id}`      |
| Tool timeout         | Agent waiting for tool > 30s | Timeout middleware, send `ping` event |
| Invalid model output | Tool name không tồn tại      | Guardrail catch, emit `agent.failed`  |
| Session not found    | Client reuse old session_id  | Return 404, client create new session |
| Auth failure         | Invalid JWT                  | Return 401, client refresh token      |
