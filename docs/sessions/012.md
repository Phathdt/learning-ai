## 1. Theory — FastAPI Application Lifecycle (20 phút)

### 1.1 Vì sao cần API layer

Ở Buổi 11, agent chạy local với configuration cố định. Production agent cần:

- **Multi-user**: mỗi user có session riêng, context riêng.
- **Streaming**: client muốn thấy agent thinking real-time, không chờ final answer.
- **Request cancellation**: user close browser → API phải stop agent gracefully.
- **Observability**: mỗi request phải correlate với agent trace, structured log.
- **Scaling**: stateless API → autoscale, sticky session cho stateful agent.
- **Versioning**: nâng cấp agent logic không làm break client cũ.

FastAPI là lựa chọn vì: async native, Pydantic validation built-in, auto OpenAPI docs, performance tương Golang.

### 1.2 FastAPI application lifecycle

```text
┌─────────────────────────────────────────────────┐
│ Application Startup                             │
├─────────────────────────────────────────────────┤
│ 1. Khởi tạo FastAPI()                           │
│ 2. Đăng ký lifespan context managers            │
│ 3. Setup middleware (auth, logging, CORS)       │
│ 4. Load config từ environment                   │
│ 5. Initialize agent runtime, LLM client, tools  │
│ 6. Test liveness: database, external APIs       │
└─────────────────────────────────────────────────┘
                     ↓
         Server accept requests
                     ↓
┌─────────────────────────────────────────────────┐
│ Request → Response Cycle (per request)          │
├─────────────────────────────────────────────────┤
│ 1. Middleware: extract auth, create request_id  │
│ 2. Dependency injection: user_id, session, logger│
│ 3. Route handler: invoke endpoint                │
│ 4. (Optional) Streaming: SSE event stream        │
│ 5. Response: JSON hoặc stream end                │
│ 6. Middleware: log request latency, response code│
└─────────────────────────────────────────────────┘
                     ↓
         On shutdown (Ctrl+C)
                     ↓
┌─────────────────────────────────────────────────┐
│ Application Shutdown                            │
├─────────────────────────────────────────────────┤
│ 1. Cancel in-flight requests gracefully          │
│ 2. Close database connections                   │
│ 3. Close external clients (LLM, vector DB)      │
│ 4. Flush logs, close observability exporter     │
│ 5. Announce shutdown in logs                    │
└─────────────────────────────────────────────────┘
```

### 1.3 Dependency Injection pattern

FastAPI dependency system cho phép define và reuse dependencies across routes.

```python
from fastapi import FastAPI, Depends, Request
from typing import Annotated
import uuid

# Define a dependency
def get_request_id(request: Request) -> str:
    return str(uuid.uuid4())

def get_user_id(authorization: str = Header(...)) -> str:
    """Extract user_id từ Authorization header"""
    # Format: "Bearer eyJhbGciOiJIUzI1NiJ9..."
    try:
        _, token = authorization.split()
        decoded = decode_jwt(token)
        return decoded["user_id"]
    except:
        raise HTTPException(401, "Invalid token")

def get_logger(request_id: Annotated[str, Depends(get_request_id)]) -> Logger:
    """Logger with request_id baked in"""
    logger = logging.getLogger("agent")
    return logger.bind(request_id=request_id)

# Use in endpoint
@app.post("/v1/agent/run")
async def agent_run(
    request: AgentRequest,
    request_id: Annotated[str, Depends(get_request_id)],
    user_id: Annotated[str, Depends(get_user_id)],
    logger: Annotated[Logger, Depends(get_logger)],
):
    logger.info(f"agent_run called for user={user_id}")
    # ...
```

Dependencies auto-resolve, cache (nếu trong cùng request), inject vào handler. Dependency cũng có thể depend trên dependency khác → DAG.

### 1.4 Pydantic schema design

Pydantic cơ bản:

```python
from pydantic import BaseModel, Field, field_validator
from typing import Optional, Literal
from datetime import datetime

# Request
class AgentRequest(BaseModel):
    task: str = Field(..., min_length=1, max_length=10000, description="Task description")
    session_id: Optional[str] = Field(None, description="Resume existing session")
    context: Optional[dict] = Field(default_factory=dict, description="Extra context")
    model: Literal["claude-sonnet-4-20250514", "claude-opus-4-1"] = Field(
        default="claude-sonnet-4-20250514"
    )

# Response
class AgentResponse(BaseModel):
    run_id: str
    session_id: str
    status: Literal["running", "completed", "failed", "cancelled"]
    result: Optional[str] = None
    error: Optional[str] = None
    iterations: int
    tokens_used: int
    duration_seconds: float
    timestamp: datetime

    model_config = {
        "json_schema_extra": {
            "example": {
                "run_id": "abc-123",
                "status": "completed",
                "result": "Found 3 TODOs...",
                "iterations": 5,
            }
        }
    }

# Validation
class AgentRequest(BaseModel):
    task: str

    @field_validator("task")
    @classmethod
    def task_not_empty(cls, v):
        if not v.strip():
            raise ValueError("task cannot be empty")
        return v.strip()
```

**Best practices**:

- Mỗi endpoint version riêng schema (`/v1/`, `/v2/`).
- Response luôn có `status` field.
- Optional field có default.
- Validation logic trong `@field_validator` thay vì trong handler.

### 1.5 SSE (Server-Sent Events) pattern

SSE là HTTP streaming từ server → client (1 chiều). Khác WebSocket (2 chiều).

```python
from fastapi.responses import StreamingResponse
import json

@app.post("/v1/agent/stream")
async def agent_stream(
    request: AgentRequest,
    user_id: str = Depends(get_user_id),
):
    """Endpoint trả về SSE stream"""

    async def event_generator():
        # Event 1: acknowledge request
        yield f"data: {json.dumps({'event': 'started', 'run_id': 'abc-123'})}\n\n"

        # Event 2–N: agent progress
        for message in agent_loop(request.task):
            yield f"data: {json.dumps({'event': 'agent.thinking', 'content': message})}\n\n"

        # Event N+1: done
        yield f"data: {json.dumps({'event': 'completed', 'result': '...'})}\n\n"

    return StreamingResponse(event_generator(), media_type="text/event-stream")
```

Client (JavaScript):

```javascript
const eventSource = new EventSource("/v1/agent/stream?task=...");
eventSource.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log(data.event, data.content);
};
eventSource.onerror = () => eventSource.close();
```

**Event format**: `data: JSON\n\n` (double newline = end of event).

### 2.2 Session model

Session là container user context qua nhiều requests.

```python
from dataclasses import dataclass
from datetime import datetime, timedelta

@dataclass
class Session:
    session_id: str
    user_id: str
    tenant_id: str
    created_at: datetime
    last_access: datetime
    metadata: dict  # extra user-specific data

    def is_expired(self, ttl_seconds: int = 3600) -> bool:
        return datetime.utcnow() - self.last_access > timedelta(seconds=ttl_seconds)

# Session store (in-memory, Redis, DB)
session_store: dict[str, Session] = {}

def get_session(session_id: str) -> Session:
    if session_id not in session_store:
        raise HTTPException(404, "Session not found")
    session = session_store[session_id]
    if session.is_expired():
        del session_store[session_id]
        raise HTTPException(401, "Session expired")
    session.last_access = datetime.utcnow()
    return session
```

### 2.3 Middleware: authentication + request tracking

```python
from starlette.middleware.base import BaseHTTPMiddleware
import uuid
from contextvars import ContextVar

request_id_var: ContextVar[str] = ContextVar("request_id")

class AuthMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        # Generate request_id
        request_id = str(uuid.uuid4())
        request_id_var.set(request_id)
        request.state.request_id = request_id

        # Extract auth
        auth_header = request.headers.get("authorization", "")
        if not auth_header.startswith("Bearer "):
            return JSONResponse({"error": "Missing Bearer token"}, status_code=401)

        token = auth_header.split()[1]
        try:
            payload = decode_jwt(token)
            request.state.user_id = payload["user_id"]
            request.state.tenant_id = payload["tenant_id"]
        except:
            return JSONResponse({"error": "Invalid token"}, status_code=401)

        response = await call_next(request)
        response.headers["X-Request-ID"] = request_id
        return response

app.add_middleware(AuthMiddleware)
```

### 2.6 Request cancellation trong streaming

Client disconnect → server phải dừng agent gracefully.

```python
import asyncio

@app.post("/v1/agent/stream")
async def agent_stream(request: AgentRequest, user_id: str = Depends(get_user_id)):
    async def event_generator():
        task = asyncio.create_task(agent_loop_async(request.task))

        try:
            async for event in task:
                yield f"data: {json.dumps(event)}\n\n"
        except asyncio.CancelledError:
            logger.info(f"stream_cancelled user={user_id}")
            yield f"data: {json.dumps({'event': 'cancelled'})}\n\n"
            task.cancel()
            raise

    return StreamingResponse(event_generator(), media_type="text/event-stream")
```

### 4.3 Skeleton code

```python
# lab_agent_api.py
import os, json, uuid, logging, jwt
from datetime import datetime, timedelta
from typing import Annotated, Optional, Literal
from contextlib import asynccontextmanager

from fastapi import FastAPI, Depends, Header, HTTPException, Request
from fastapi.responses import JSONResponse, StreamingResponse
from pydantic import BaseModel, Field, field_validator
from anthropic import Anthropic
import structlog

# ============ Config ============
JWT_SECRET = os.getenv("JWT_SECRET", "secret")
MODEL = "claude-sonnet-4-20250514"
SESSION_TTL = 3600  # 1 hour

# ============ Models ============
class AgentRequest(BaseModel):
    task: str = Field(..., min_length=1, max_length=10000)
    session_id: Optional[str] = None
    model: Literal["claude-sonnet-4-20250514", "claude-opus-4-1"] = MODEL

    @field_validator("task")
    @classmethod
    def task_not_empty(cls, v):
        return v.strip()

class AgentResponse(BaseModel):
    run_id: str
    session_id: str
    status: Literal["completed", "failed", "cancelled"]
    result: Optional[str] = None
    error: Optional[str] = None
    iterations: int
    duration_seconds: float
    timestamp: datetime

class ErrorDetail(BaseModel):
    code: str
    message: str
    details: Optional[dict] = None

class ErrorResponse(BaseModel):
    error: ErrorDetail
    request_id: str
    timestamp: datetime

# ============ Session store (in-memory) ============
session_store: dict = {}

class Session:
    def __init__(self, user_id: str, tenant_id: str):
        self.session_id = str(uuid.uuid4())
        self.user_id = user_id
        self.tenant_id = tenant_id
        self.created_at = datetime.utcnow()
        self.last_access = datetime.utcnow()
        self.metadata = {}

    def is_valid(self) -> bool:
        elapsed = (datetime.utcnow() - self.last_access).total_seconds()
        return elapsed < SESSION_TTL

    def touch(self):
        self.last_access = datetime.utcnow()

# ============ Logger setup ============
structlog.configure(
    processors=[
        structlog.processors.JSONRenderer()
    ],
    wrapper_class=structlog.make_filtering_bound_logger(logging.INFO),
)

def get_logger(request_id: str):
    return structlog.get_logger().bind(request_id=request_id)

# ============ Dependencies ============
def get_request_id() -> str:
    return str(uuid.uuid4())

def get_user_from_token(authorization: str = Header(...)) -> tuple[str, str]:
    """Extract user_id, tenant_id từ JWT"""
    try:
        if not authorization.startswith("Bearer "):
            raise ValueError("Invalid format")
        token = authorization.split(" ")[1]
        payload = jwt.decode(token, JWT_SECRET, algorithms=["HS256"])
        return payload["user_id"], payload["tenant_id"]
    except:
        raise HTTPException(401, "Invalid token")

def get_session_or_create(
    user_id: str,
    tenant_id: str,
    session_id: Optional[str] = None,
) -> Session:
    """Get existing session hoặc tạo mới"""
    if session_id:
        if session_id not in session_store:
            raise HTTPException(404, "Session not found")
        session = session_store[session_id]
        if not session.is_valid():
            del session_store[session_id]
            raise HTTPException(401, "Session expired")
        session.touch()
        return session

    session = Session(user_id, tenant_id)
    session_store[session.session_id] = session
    return session

# ============ Routes ============
@asynccontextmanager
async def lifespan(app: FastAPI):
    # Startup
    logger = structlog.get_logger()
    logger.info("app_starting")
    yield
    # Shutdown
    logger.info("app_shutdown")

app = FastAPI(
    title="Agent API",
    version="1.0.0",
    lifespan=lifespan
)
client = Anthropic(api_key=os.getenv("ANTHROPIC_API_KEY"))

@app.post("/v1/agent/run")
async def agent_run(
    request: AgentRequest,
    request_id: Annotated[str, Depends(get_request_id)],
    auth: Annotated[tuple, Depends(get_user_from_token)],
) -> AgentResponse:
    """Synchronous: run agent, return full result"""
    user_id, tenant_id = auth
    logger = get_logger(request_id)

    try:
        session = get_session_or_create(user_id, tenant_id, request.session_id)

        logger.info(
            "agent_run_start",
            user_id=user_id,
            session_id=session.session_id,
            task_length=len(request.task),
        )

        start_time = datetime.utcnow()

        # Call LLM (simplified: no tools)
        resp = client.messages.create(
            model=request.model,
            max_tokens=2048,
            messages=[{"role": "user", "content": request.task}]
        )

        result = resp.content[0].text
        duration = (datetime.utcnow() - start_time).total_seconds()

        logger.info(
            "agent_run_completed",
            session_id=session.session_id,
            duration_seconds=duration,
            result_length=len(result),
        )

        return AgentResponse(
            run_id=str(uuid.uuid4()),
            session_id=session.session_id,
            status="completed",
            result=result,
            iterations=1,
            duration_seconds=duration,
            timestamp=datetime.utcnow(),
        )

    except HTTPException:
        raise
    except Exception as e:
        logger.error("agent_run_error", error=str(e))
        raise HTTPException(500, f"Agent error: {str(e)}")

@app.post("/v1/agent/stream")
async def agent_stream(
    request: AgentRequest,
    request_id: Annotated[str, Depends(get_request_id)],
    auth: Annotated[tuple, Depends(get_user_from_token)],
):
    """Streaming: SSE events"""
    user_id, tenant_id = auth
    logger = get_logger(request_id)

    session = get_session_or_create(user_id, tenant_id, request.session_id)

    async def event_generator():
        logger.info(
            "stream_start",
            session_id=session.session_id,
            user_id=user_id,
        )

        yield f"data: {json.dumps({'event': 'started', 'session_id': session.session_id})}\n\n"

        try:
            # Stream LLM output (if streaming supported)
            with client.messages.stream(
                model=request.model,
                max_tokens=2048,
                messages=[{"role": "user", "content": request.task}]
            ) as stream:
                content = ""
                for text in stream.text_stream:
                    content += text
                    yield f"data: {json.dumps({'event': 'agent.token', 'content': text})}\n\n"

                logger.info("stream_completed", session_id=session.session_id)
                yield f"data: {json.dumps({'event': 'completed', 'result': content})}\n\n"

        except Exception as e:
            logger.error("stream_error", session_id=session.session_id, error=str(e))
            yield f"data: {json.dumps({'event': 'error', 'message': str(e)})}\n\n"

    return StreamingResponse(event_generator(), media_type="text/event-stream")

@app.get("/health")
async def health_check():
    """Liveness probe"""
    return {"status": "healthy"}

@app.get("/readiness")
async def readiness_check():
    """Readiness probe"""
    try:
        # Test LLM client
        client.messages.create(
            model="claude-opus-4-1",
            max_tokens=10,
            messages=[{"role": "user", "content": "hi"}]
        )
        return {"status": "ready"}
    except:
        return JSONResponse({"status": "not_ready"}, status_code=503)

@app.exception_handler(Exception)
async def general_exception_handler(request: Request, exc: Exception):
    request_id = getattr(request.state, "request_id", "unknown")
    return JSONResponse(
        status_code=500,
        content=ErrorResponse(
            error=ErrorDetail(
                code="internal_error",
                message=str(exc)
            ),
            request_id=request_id,
            timestamp=datetime.utcnow()
        ).model_dump()
    )
```

```python
# test_api.py
import requests
import json
import jwt
import os
from datetime import datetime, timedelta

JWT_SECRET = os.getenv("JWT_SECRET", "secret")
API_URL = "http://localhost:8000"

def create_token(user_id="user_123", tenant_id="tenant_456"):
    payload = {
        "user_id": user_id,
        "tenant_id": tenant_id,
        "exp": datetime.utcnow() + timedelta(hours=1)
    }
    return jwt.encode(payload, JWT_SECRET, algorithm="HS256")

def test_sync_endpoint():
    token = create_token()
    headers = {
        "Authorization": f"Bearer {token}",
        "Content-Type": "application/json"
    }

    response = requests.post(
        f"{API_URL}/v1/agent/run",
        json={"task": "What is the capital of France?"},
        headers=headers
    )

    print(f"Status: {response.status_code}")
    data = response.json()
    print(f"Session ID: {data['session_id']}")
    print(f"Result: {data['result']}")

def test_stream_endpoint():
    token = create_token()
    headers = {
        "Authorization": f"Bearer {token}",
        "Content-Type": "application/json"
    }

    response = requests.post(
        f"{API_URL}/v1/agent/stream",
        json={"task": "List 3 reasons why Python is great."},
        headers=headers,
        stream=True
    )

    print(f"Status: {response.status_code}")
    for line in response.iter_lines():
        if line:
            if line.startswith(b"data: "):
                event = json.loads(line[6:])
                print(f"Event: {event['event']}")
                if "content" in event:
                    print(f"  Content: {event['content']}")

def test_health():
    response = requests.get(f"{API_URL}/health")
    print(f"Health: {response.json()}")

if __name__ == "__main__":

    test_health()

    test_sync_endpoint()
```
