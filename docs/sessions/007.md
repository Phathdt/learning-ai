## 1. Theory — Agent Observability và Evaluation (20 phút)

### 1.1 Vì sao agent evaluation khác traditional testing

Traditional API test: input → oracle → pass/fail. Deterministic.

Agent: input → trajectory (10+ turns) → output. **Trajectory quyết định output, không phải chỉ input.**

Ví dụ: task "tìm bug trong file X"

- Turn 1: agent đọc file → có bug
- Turn 2: agent tìm giải pháp → đúng
- Final: output đúng ✓

Nhưng nếu change retrieval (Buổi 5), model (Buổi 18), hoặc tool (Buổi 3) → trajectory thay đổi, output có thể sai dù input không đổi.

**Eval agent cần:**

- Capture toàn bộ trajectory (trace).
- Đo lường intermediate steps (tool selection, retrieval quality, reasoning).
- Detect quality regression trước khi ship.

### 1.2 Observability: Signal points trong agent loop

```
User Request
    ↓ [SIGNAL: input_text, user_id, intent, expected_output]
Build Context
    ↓ [SIGNAL: system_prompt_tokens, retrieval_results, memory_size, total_context_tokens]
Model Call
    ↓ [SIGNAL: model, temperature, max_tokens, prompt_hash]
Decision
    ↓ [SIGNAL: stop_reason, output_tokens, model_latency_ms, input_cost, output_cost]
Tool Call
    ↓ [SIGNAL: tool_name, args, permission_check_result]
Execute Tool
    ↓ [SIGNAL: tool_latency_ms, success/error, tool_cost]
Observe Result
    ↓ [SIGNAL: result_tokens, result_quality (retrieved vs hallucinated)]
Model (turn 2)
    ↓ ...
Final Output
    ↓ [SIGNAL: final_answer_text, reasoning_depth, confidence_score, total_cost, total_latency_ms]
```

**9 categories của observability signals:**

| Category        | Signals                                     | Dùng để                                   |
| --------------- | ------------------------------------------- | ----------------------------------------- |
| **Input**       | text, user_id, metadata                     | Phân loại request, multi-tenant filtering |
| **Model**       | model_name, temperature, version            | Track model impact trên quality           |
| **Prompt**      | system_prompt, prompt_hash                  | Trace prompt version, consistency         |
| **Context**     | retrieval_results, memory_size, token_count | Detect context phá hủy quality            |
| **Tool calls**  | tool_name, args, count                      | Trace decision path, repeated calls       |
| **Retrieval**   | doc_ids, scores, count                      | Evals retrieval quality                   |
| **Latency**     | model_ms, tool_ms, e2e_ms                   | Detect slow operations                    |
| **Token usage** | input, output, cache_read                   | Track cost per step                       |
| **Cost**        | per_model_call, per_tool, total             | Optimize cost vs quality tradeoff         |
| **Output**      | text, confidence, errors                    | Final quality assessment                  |

Langfuse captures hầu hết tự động; bài tập là thêm custom signals vào.

### 1.3 Evaluation dimensions

**9 chiều để đánh giá agent:**

| Chiều                    | Định nghĩa                                      | Evaluator                             | Rủi ro nếu thiếu      |
| ------------------------ | ----------------------------------------------- | ------------------------------------- | --------------------- |
| **Final answer quality** | Output có trả lời đúng câu hỏi không            | Human, LLM-as-judge                   | Deploy sai tính toán  |
| **Task success**         | Đạt goal đặt ra? (test pass, file edited, ...)  | Oracle, rule-based                    | Agent dừng sớm        |
| **Tool selection**       | Model có chọn tool đúng không                   | Rule-based (whitelist vs blacklist)   | Tool gọi sai context  |
| **Tool arguments**       | Arguments có hợp lệ schema không                | Pydantic validator, code evaluator    | Tool crash            |
| **Retrieval relevance**  | Retrieved docs có liên quan không               | LLM-as-judge ("is_relevant")          | RAG độ chính xác thấp |
| **Groundedness**         | Answer có được support bởi retrieved docs không | LLM-as-judge ("is_grounded")          | Hallucination         |
| **Safety**               | Output có vi phạm policy không                  | Rule-based (regex, keyword blocklist) | Hành vi nguy hiểm     |
| **Latency**              | Thời gian end-to-end < threshold không          | Numeric threshold                     | SLA violation         |
| **Cost**                 | Tổng cost < budget không                        | Numeric threshold                     | Vượt budget           |

**Metrik composite**: `quality_score = 0.5 * answer_quality + 0.3 * safety + 0.2 * retrieval_relevance`.

### 1.4 Evaluation levels

| Level          | Scope                                          | Dùng khi                                 |
| -------------- | ---------------------------------------------- | ---------------------------------------- |
| **Unit**       | Một tool (search_todos, query_db)              | Tester chạy trước Buổi 3                 |
| **Component**  | Một module (Planner node, Retriever, Verifier) | Tester chạy trước integrate vào graph    |
| **Trajectory** | Toàn bộ agent loop 1 task                      | Eval trước release                       |
| **End-to-end** | Agent vs real user request                     | Staging, smoke test                      |
| **Production** | Production traces collected live               | Continuous monitoring, detect regression |

Buổi 7 tập trung vào **trajectory + component levels** offline.

## 2. Deep dive — Eval dataset, Evaluators, Experiments (35 phút)

### 2.1 Dataset design

**5 loại case cần có:**

| Loại            | Ví dụ (Operations Agent)                                                  | Số lượng | Mục đích                      |
| --------------- | ------------------------------------------------------------------------- | -------- | ----------------------------- |
| **Golden**      | "Doanh thu tháng này là bao nhiêu?" → truy query, format, trả lời         | 10+      | Baseline quality              |
| **Edge case**   | "Top 3 khách hàng theo revenue?" vs "Khách hàng nào có revenue cao nhất?" | 5+       | Prompt engineering robustness |
| **Failure**     | Agent gọi tool sai, hallucinate, retrieve sai doc                         | 3+       | Debug mode                    |
| **Regression**  | Case từ production incident cần chắc chắn không xảy ra lại                | 2+       | CI gate                       |
| **Adversarial** | "Hôm nay là ngày bao nhiêu tháng 15?" (impossible date)                   | 2+       | Safety, edge handling         |

**Dataset format:**

```python
[
  {
    "id": "golden-001",
    "type": "golden",
    "input": "Doanh thu hôm qua là bao nhiêu?",
    "expected_output": {
      "answer": "Doanh thu hôm qua là 50,000 đồng",
      "should_query_db": True,
      "tool_sequence": ["query_db"],
      "hallucination_allowed": False
    },
    "metadata": {"user_id": "user_001", "created_at": "2026-09-20"}
  },
  {
    "id": "regression-001",
    "type": "regression",
    "input": "Các order của khách X từ tháng trước?",
    "expected_output": { ... },
    "issue_context": "Production incident 2026-09-15: agent trả về orders của khách Y thay vì X → phá dữ liệu",
    "must_pass": True
  }
]
```

### 2.2 Evaluator types

**4 loại evaluator:**

| Loại             | Implement                                         | Trade-off                         | Code                                               |
| ---------------- | ------------------------------------------------- | --------------------------------- | -------------------------------------------------- |
| **Exact/Code**   | `expected == actual` hoặc oracle (test, compiler) | Công cứng, không match paraphrase | `assert output == expected`                        |
| **Rule-based**   | Regex, keyword, schema validator                  | Cần tuning rule                   | Pydantic, langchain `StringEvaluator`              |
| **LLM-as-judge** | Gọi model để đánh giá (hoặc dùng Langfuse eval)   | Chậm, non-deterministic           | `client.messages.create(prompt=f"Rate: {output}")` |
| **Human review** | Con người đánh giá                                | Chính xác nhưng không scale       | Langfuse dashboard                                 |

Code mẫu 3 loại:

```python
# 1. Exact evaluator
def eval_exact(output: str, expected: str) -> dict:
    return {"passed": output.strip() == expected.strip(), "score": 1.0 if output.strip() == expected.strip() else 0.0}

# 2. Rule-based: kiểm tra answer chứa số tiền
def eval_contains_currency(output: str) -> dict:
    import re
    has_currency = bool(re.search(r'\d+[\.,]\d+ (đồng|usd|€)', output))
    return {"passed": has_currency, "score": 1.0 if has_currency else 0.0}

# 3. LLM-as-judge
def eval_llm_judge(output: str, expected: str, client) -> dict:
    prompt = f"""
    Expected: {expected}
    Actual: {output}

    Is the actual output correct? (yes/no/partial)
    """
    resp = client.messages.create(
        model="claude-sonnet-4-20250514",
        max_tokens=100,
        messages=[{"role": "user", "content": prompt}]
    )
    result_text = resp.content[0].text.lower()
    score = 1.0 if "yes" in result_text else (0.5 if "partial" in result_text else 0.0)
    return {"passed": score >= 0.9, "score": score, "reasoning": result_text}
```

### 2.3 Experiment workflow

```
Baseline (current agent)
     ↓ run on eval_dataset
     ├── metric_1: accuracy=92%, cost=$0.50, latency=1.2s
     └── failed_cases: [regression-001, edge-case-003]

Candidate (new agent with change X)
     ↓ run on eval_dataset
     ├── metric_1: accuracy=94%, cost=$0.48, latency=1.1s
     └── failed_cases: [edge-case-002]

Compare
     ├── accuracy: +2% (good)
     ├── cost: -4% (good)
     ├── latency: -8% (good)
     └── regression-001: baseline fail → candidate fail (still bad)

Decision
     ├── New regressions? None ✓
     ├── Quality improvement? +2% ✓
     └── APPROVED (merge to main)
```

### 2.4 Regression suite

Regression cases là CI gate. Nếu experiment candidate fail bất kỳ regression case nào, từ chối merge.

```python
REGRESSION_CASES = [
    "regression-001",  # Incident 2026-09-15: cross-tenant data leak
    "regression-002",  # Incident 2026-09-18: agent loop infinite
]

def run_regression_check(agent, eval_dataset):
    failed = []
    for case_id in REGRESSION_CASES:
        case = find_case(eval_dataset, case_id)
        output = agent.run(case["input"])
        evaluator = get_evaluator(case["expected_output"])
        result = evaluator(output, case["expected_output"])
        if not result["passed"]:
            failed.append((case_id, result))

    if failed:
        raise Exception(f"Regression check failed: {failed}")
    print("All regression cases passed ✓")
```

```python
from langfuse import Langfuse

langfuse = Langfuse()

def run_baseline_agent(task: str, dataset_id: str):
    trace = langfuse.trace(name="baseline-agent", input={"task": task, "dataset_id": dataset_id})

    # Agent loop (simplified)
    messages = [{"role": "user", "content": task}]

    for turn in range(3):  # Max 3 turns

            resp = client.messages.create(
                model="claude-sonnet-4-20250514",
                messages=messages,
                system="You are an agent. Reason step by step.",
                max_tokens=500
            )

            # Log token usage
            trace.event(name="model_call", output={
                "input_tokens": resp.usage.input_tokens,
                "output_tokens": resp.usage.output_tokens,
                "stop_reason": resp.stop_reason
            })

            messages.append({"role": "assistant", "content": resp.content[0].text})

            if resp.stop_reason == "end_turn":
                break

    output_text = messages[-1]["content"]
    trace.update(output={"answer": output_text})
    return output_text
```

```python
from pydantic import BaseModel, ValidationError

# ============ Evaluators ============
class EvaluationResult(BaseModel):
    passed: bool
    score: float  # 0.0 - 1.0
    reason: str | None = None

def eval_exact(output: str, expected: str) -> EvaluationResult:
    passed = output.strip() == expected.strip()
    return EvaluationResult(passed=passed, score=1.0 if passed else 0.0)

def eval_rule_based(output: str, expected_spec: dict) -> EvaluationResult:
    """Check if output matches rule specification"""
    reasons = []
    score = 1.0

    # Check "should contain"
    for phrase in expected_spec.get("answer_contains", []):
        if phrase.lower() not in output.lower():
            score *= 0.8
            reasons.append(f"Missing: '{phrase}'")

    # Check "should have number"
    if expected_spec.get("should_have_number"):
        import re
        if not re.search(r'\d+', output):
            score *= 0.5
            reasons.append("No number found")

    # Check "should be safe"
    if expected_spec.get("should_be_safe"):
        dangerous = ["xóa", "delete", "DROP TABLE"]
        if any(d in output for d in dangerous):
            score = 0.0
            reasons.append("Unsafe output detected")

    passed = score >= 0.9
    return EvaluationResult(passed=passed, score=score, reason="; ".join(reasons) if reasons else None)

def eval_llm_judge(output: str, case: dict, client) -> EvaluationResult:
    """Use LLM to judge output quality"""
    expected_spec = json.dumps(case["expected_output"], ensure_ascii=False, indent=2)

    prompt = f"""
    Task: {case["input"]}

    Expected behavior:
    {expected_spec}

    Actual output:
    {output}

    Evaluate:
    1. Does output satisfy the expected behavior? (yes/no)
    2. Any safety concerns? (yes/no)
    3. Overall score 0-100

    Respond in JSON: {{"passed": bool, "score": int, "reason": str}}
    """

    resp = client.messages.create(
        model=MODEL,
        max_tokens=200,
        messages=[{"role": "user", "content": prompt}]
    )

    import json
    try:
        result = json.loads(resp.content[0].text)
        return EvaluationResult(
            passed=result["passed"],
            score=result["score"] / 100.0,
            reason=result.get("reason")
        )
    except:
        return EvaluationResult(passed=False, score=0.0, reason="LLM judge parse error")

# ============ Baseline Agent ============
def baseline_agent(task: str, trace_name: str = "baseline") -> tuple[str, dict]:
    """Simple agent loop without retrieval reranking"""
    trace = langfuse.trace(name=trace_name, input={"task": task})

    messages = [{"role": "user", "content": task}]
    tool_calls_count = 0
    total_tokens = {"input": 0, "output": 0}

    for turn in range(1, 4):  # Max 3 turns
        span = trace.span(name=f"turn_{turn}")

        resp = client.messages.create(
            model=MODEL,
            max_tokens=512,
            messages=messages,
            system="Bạn là một agent thông minh. Trả lời câu hỏi dựa vào kiến thức và logic.",
        )

        total_tokens["input"] += resp.usage.input_tokens
        total_tokens["output"] += resp.usage.output_tokens

        span.event(
            name="model_call",
            output={
                "stop_reason": resp.stop_reason,
                "input_tokens": resp.usage.input_tokens,
                "output_tokens": resp.usage.output_tokens
            }
        )

        messages.append({"role": "assistant", "content": resp.content[0].text})

        if resp.stop_reason == "end_turn":
            break

        tool_calls_count += 1

    output = messages[-1]["content"]
    trace.update(output={"answer": output, "turns": len(messages) // 2, "tools_called": tool_calls_count})
    span.end()

    return output, {"tokens": total_tokens, "turns": len(messages) // 2}

# ============ Candidate Agent ============
def candidate_agent(task: str, trace_name: str = "candidate") -> tuple[str, dict]:
    """Enhanced agent with change X (e.g., structured system prompt)"""
    trace = langfuse.trace(name=trace_name, input={"task": task})

    messages = [{"role": "user", "content": task}]
    total_tokens = {"input": 0, "output": 0}

    for turn in range(1, 4):
        span = trace.span(name=f"turn_{turn}")

        resp = client.messages.create(
            model=MODEL,
            max_tokens=512,
            messages=messages,
            system="""Bạn là một agent thông minh.
Trả lời câu hỏi theo các bước:
1. Hiểu rõ yêu cầu
2. Lập kế hoạch
3. Thực hiện
4. Kiểm tra kết quả""",
        )

        total_tokens["input"] += resp.usage.input_tokens
        total_tokens["output"] += resp.usage.output_tokens

        span.event(name="model_call", output={
            "stop_reason": resp.stop_reason,
            "input_tokens": resp.usage.input_tokens,
            "output_tokens": resp.usage.output_tokens
        })

        messages.append({"role": "assistant", "content": resp.content[0].text})

        if resp.stop_reason == "end_turn":
            break

    output = messages[-1]["content"]
    trace.update(output={"answer": output, "turns": len(messages) // 2})
    span.end()

    return output, {"tokens": total_tokens, "turns": len(messages) // 2}

# ============ Main ============
if __name__ == "__main__":
    print("=== Experiment: Baseline vs Candidate ===\n")

    baseline_results = []
    candidate_results = []

    for case in EVAL_DATASET:
        print(f"Running case {case['id']}...")

        # Baseline
        baseline_output, baseline_meta = baseline_agent(case["input"], f"baseline-{case['id']}")
        baseline_eval = eval_rule_based(baseline_output, case["expected_output"])
        baseline_results.append({
            "case_id": case["id"],

            "passed": baseline_eval.passed,
            "score": baseline_eval.score,
            "meta": baseline_meta

        # Candidate

        candidate_eval = eval_rule_based(candidate_output, case["expected_output"])
        candidate_results.append({
            "case_id": case["id"],
            "type": case["type"],
            "passed": candidate_eval.passed,
            "score": candidate_eval.score,
            "meta": candidate_meta
        })

    # Summary
    baseline_accuracy = sum(1 for r in baseline_results if r["passed"]) / len(baseline_results)
    candidate_accuracy = sum(1 for r in candidate_results if r["passed"]) / len(candidate_results)

    print(f"\n=== Results ===")
    print(f"Baseline accuracy: {baseline_accuracy:.1%}")
    print(f"Candidate accuracy: {candidate_accuracy:.1%}")
    print(f"Improvement: {(candidate_accuracy - baseline_accuracy):.1%}")

    # Regression check
    regression_cases = [r for r in baseline_results if r["type"] == "regression"]
    regression_passed = all(r["passed"] for r in regression_cases if any(rc["case_id"] == r["case_id"] for rc in candidate_results))
    print(f"Regression check: {'PASS' if regression_passed else 'FAIL'}")

    # Save results
    with open("experiment_results.json", "w") as f:
        json.dump({
            "timestamp": datetime.now().isoformat(),
            "baseline": baseline_results,
            "candidate": candidate_results,
            "summary": {
                "baseline_accuracy": baseline_accuracy,
                "candidate_accuracy": candidate_accuracy,
                "improvement": candidate_accuracy - baseline_accuracy,
                "regression_passed": regression_passed
            }
        }, f, indent=2, ensure_ascii=False)

    print(f"\nResults saved to experiment_results.json")
```
