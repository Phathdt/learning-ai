## 1. Theory — Tool Calling và Tool Design (20 phút)

### 1.1 Tool calling cơ bản (nhắc lại từ Buổi 1)

Tool calling không phải model chạy tool. Model **đề xuất** tool call (name + arguments), harness **chạy** tool, harness **gửi kết quả** lại model.

```python
response = client.messages.create(
    model=MODEL, tools=TOOLS, messages=messages
)
# response.stop_reason == "tool_use" → model muốn gọi tool
# harness kiểm tra quyền, validate input, chạy tool, append result vào messages
```

Điểm mấu chốt: **ranh giới giữa trusted code (harness) và untrusted proposal (model output)** định hình safety.

### 1.2 Tool contract: schema, description, error semantics

Tool tốt cần 5 phần:

| Phần                | Mục đích                                   | Ví dụ                                                         |
| ------------------- | ------------------------------------------ | ------------------------------------------------------------- |
| **Name**            | Duy nhất, descriptive, snake_case          | `query_read_only_db`, `search_documents`                      |
| **Description**     | Ngắn, nêu rõ scope + constraint            | "Truy vấn DB chỉ đọc. Hỗ trợ SELECT, không UPDATE"            |
| **Input schema**    | Pydantic TypedDict, tất cả fields explicit | `{"query": {"type": "string"}, "limit": {"type": "integer"}}` |
| **Output**          | Deterministic, consistent format           | `{"success": bool, "data": list, "error": str\|null}`         |
| **Error semantics** | Lỗi phải rõ ràng, không generic            | `"SQL_INJECTION_DETECTED"` không phải `"Error"`               |

Code mẫu tool definition:

```python
from pydantic import BaseModel, Field

class QueryDBInput(BaseModel):
    query: str = Field(
        ...,
        description="SELECT query. Không được chứa INSERT/UPDATE/DELETE.",
        min_length=1,
        max_length=1000
    )
    limit: int = Field(default=100, ge=1, le=1000, description="Số hàng tối đa")

TOOLS = [{
    "name": "query_read_only_db",
    "description": "Truy vấn bảng công khai trong DB chỉ đọc. Không được ghi dữ liệu.",
    "input_schema": QueryDBInput.model_json_schema()
}]
```

### 1.3 Tool design principles

| Nguyên tắc                        | Định nghĩa                                                     | Vi phạm                                         |
| --------------------------------- | -------------------------------------------------------------- | ----------------------------------------------- |
| **Narrow responsibility**         | Một tool làm một việc tốt                                      | Một tool vừa query DB vừa call API vừa ghi file |
| **Deterministic**                 | Input giống nhau → output giống nhau, lặp lại được             | Tool output phụ thuộc vào random seed           |
| **Permission boundary**           | Explicit scope (schema, resource list), not checked at runtime | Tool "có quyền" check bằng try-catch exception  |
| **Predictable error**             | Lỗi có ý nghĩa, không generic                                  | Tất cả lỗi return `{"error": "Unknown"}`        |
| **Idempotency (nếu side effect)** | N lần gọi = 1 lần gọi, không tác động dư                       | Tool ghi file không check đã tồn tại            |
| **Observable**                    | Log execution: args, result, latency, user                     | Tool chạy im lặng, không trace được             |
| **Testable**                      | Unit test độc lập, mock external                               | Tool phụ thuộc trạng thái toàn bộ hệ thống      |

### 1.4 Tool categories (8 loại)

| Category       | Ví dụ tool                         | Scope                              | Rủi ro chính                      |
| -------------- | ---------------------------------- | ---------------------------------- | --------------------------------- |
| **Database**   | query_db, read_table               | SELECT, schema discovery           | Rò rỉ dữ liệu, SQL injection      |
| **SQL**        | execute_sql, analyze_query         | Parameterized query, explain plan  | Syntax error, timeout             |
| **API**        | call_external_api, webhook         | HTTP method, endpoint, auth        | Rate limit, data leakage          |
| **Search**     | search_knowledge, semantic_search  | Query, filters, top-k              | Hallucination, irrelevant result  |
| **RAG**        | retrieve_document, chunk_search    | Vector DB, similarity              | Cross-tenant leakage, staleness   |
| **Filesystem** | read_file, list_dir, write_file    | Path boundaries, permissions       | Read secret, traverse parent      |
| **Sandbox**    | execute_code, run_test             | Resource limit (CPU, memory, time) | Escape, DoS, crash                |
| **Business**   | send_email, create_ticket, payment | Idempotency key, audit             | Duplicate action, wrong recipient |

Mỗi category có constraint riêng, không dùng "magic tool" xử lý tất cả.

## 2. Deep dive — MCP Architecture và Security (25 phút)

### 2.1 MCP (Model Context Protocol) overview

MCP là protocol cho phép LLM host (Claude Code, Claude API) kết nối với remote tool servers. Thay vì embed tool vào harness, tool chạy ở server độc lập, harness query chúng qua network.

Tại sao: **isolation, scalability, security boundary, version independence**.

```text
┌──────────────┐                    ┌─────────────────┐
│   Agent Host │                    │  MCP Server     │
│  (Claude)    │◄────JSON-RPC────►  │  (remote)       │
│              │                    │  Tool: query_db │
│  Tool list   │   list_tools()     │  Tool: call_api │
│  Tool call   │   call_tool()      │                 │
└──────────────┘                    └─────────────────┘
```

### 2.2 MCP components

| Thành phần               | Chức năng                                         | Ví dụ                                       |
| ------------------------ | ------------------------------------------------- | ------------------------------------------- |
| **Host**                 | Khởi tạo tool từ config, gọi server, xử lý result | Claude Code, Agent Runner                   |
| **Client**               | Kết nối đến server, gửi RPC request               | MCP client SDK                              |
| **Server**               | Expose tool, xử lý request, gửi response          | `mcp-server-db`, custom server              |
| **Tools**                | Hàm có schema, thực thi side effect hoặc đọc      | `query_db(sql: string)`                     |
| **Resources**            | Dữ liệu read-only, không có action                | Schema metadata, documentation              |
| **Prompts/Capabilities** | Instruction cho model, system prompt              | "Bạn có quyền query DB staging, không prod" |
| **Transport**            | Giao thức I/O                                     | Stdio (local), HTTP/SSE (remote)            |
| **Authentication**       | Xác thực client                                   | API key, JWT                                |

### 2.3 MCP communication flow

```text
1. Host startup:
   config: { "mcpServers": { "db": { "command": "python", "args": ["server.py"] } } }

2. Host connect:
   Host spawn process → MCP Server
   Host ← capabilities (tools=[], resources=[])

3. Agent request tool:
   Model đề xuất: {"type": "tool_use", "name": "query_db", "input": {"sql": "SELECT ..."}}

4. Host call server:
   Host → call_tool("query_db", {"sql": "...", "auth": "key123"})
   MCP Server ← verify auth, validate input, execute, return result
   Host ← {"success": true, "data": [...]}

5. Append result:
   Host append {"role": "user", "content": [{"type": "tool_result", ...}]}
   Model continue
```

### 2.4 Security: least privilege, auth, audit

**Least privilege**: Model chỉ thấy tool mà nó cần, không thấy "tất cả tool có trên server".

```python
# Config host: chỉ expose query_read_only_db, ẩn cả query_admin_panel
capabilities = [
    {
        "name": "query_read_only_db",
        "description": "...",
        "input_schema": {...}
    }
    # query_admin_panel không khai báo → model không biết tồn tại
]
```

**Authentication (xác thực)**: Client là ai? Server verify trước khi chạy tool.

```python
# Header: Authorization: Bearer <API_KEY>
# Server kiểm tra:
if request.headers.get("Authorization") != f"Bearer {VALID_KEY}":
    raise AuthError("Invalid API key")
```

**Authorization (phân quyền)**: Client được phép làm gì? Mỗi tool có scope.

```python
# Tool query_db chỉ được query những table public_users, public_products
# Không được query internal_logs, sensitive_data
ALLOWED_TABLES = ["public_users", "public_products"]

def query_db(sql: str, auth_token: str):
    # Parse SQL, extract table name
    table = extract_table_from_sql(sql)
    if table not in ALLOWED_TABLES:
        raise AuthError(f"Table {table} not allowed")
    execute_sql(sql)
```

**Audit trail (ghi chép)**: WHO did WHAT, WHEN, on WHICH RESOURCE, with WHAT RESULT.

```python
def audit_log(user_id: str, tool_name: str, input_args: dict, result: dict, latency_ms: int):
    log = {
        "timestamp": datetime.now().isoformat(),
        "user_id": user_id,
        "tool": tool_name,
        "input": input_args,  # Nhưng không log password/token!
        "result_summary": result.get("success"),
        "latency_ms": latency_ms,
        "error": result.get("error")
    }
    logger.info(json.dumps(log))
    # Lưu vào DB để query sau
```

**Rate limiting**: Chặn abuse. Mỗi user tối đa N request/phút.

```python
from ratelimit import limits, sleep_and_retry

@sleep_and_retry
@limits(calls=100, period=60)  # 100 calls per 60s
def query_db(sql: str, user_id: str):
    execute_sql(sql)
```

### 2.5 Security failure modes

| Failure mode               | Triệu chứng                                            | Nguyên nhân                                       | Fix                                  |
| -------------------------- | ------------------------------------------------------ | ------------------------------------------------- | ------------------------------------ |
| **Unauthorized tool call** | Model gọi tool không được phép (không trong allowlist) | Host không filter tool list, hoặc config sai      | Explicit allowlist, test mỗi startup |
| **SQL injection**          | Hacker input `"; DROP TABLE; --"` → query thực thi     | Tool ghép string thay parameterized query         | Bind parameters, validate table name |
| **Credential leak**        | Log chứa API key, token → hiển thị trong trace         | Audit log naive dump tất cả argument              | Filter sensitive field trước log     |
| **Cross-tenant data leak** | User A query được dữ liệu của User B                   | Authorization check yếu (missing WHERE tenant_id) | Per-tenant row-level security (RLS)  |
| **Tool result injection**  | Tool return `{"data": "'; DROP"}` → model execute      | Model parse JSON result không escape              | Trusted parsing, validate schema     |

## 3. Demo — Instructor (15 phút)

### 3.1 Server-side: simple_db_server.py

```python
# simple_db_server.py — MCP server exposing query_read_only_db
import json, sqlite3, logging, time
from datetime import datetime
from typing import Any

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

DB_PATH = ":memory:"
VALID_KEYS = ["demo-key-123"]

def init_db():
    conn = sqlite3.connect(DB_PATH)
    conn.execute("""
        CREATE TABLE IF NOT EXISTS users (
            id INTEGER PRIMARY KEY,
            name TEXT,
            email TEXT,
            created_at DATETIME DEFAULT CURRENT_TIMESTAMP
        )
    """)
    conn.execute("INSERT INTO users (name, email) VALUES ('Alice', 'alice@example.com')")
    conn.execute("INSERT INTO users (name, email) VALUES ('Bob', 'bob@example.com')")
    conn.commit()
    conn.close()

def query_read_only_db(sql: str, auth_key: str) -> dict:
    """Read-only database query tool"""
    start = time.time()

    # 1. Authenticate
    if auth_key not in VALID_KEYS:
        logger.warning(f"auth_failed user_key={auth_key[:10]}...")
        return {"success": False, "error": "UNAUTHORIZED"}

    # 2. Validate: only SELECT
    sql_upper = sql.upper().strip()
    if not sql_upper.startswith("SELECT"):
        logger.warning(f"invalid_query user={auth_key} query={sql[:50]}")
        return {"success": False, "error": "ONLY_SELECT_ALLOWED"}

    if any(word in sql_upper for word in ["INSERT", "UPDATE", "DELETE", "DROP"]):
        logger.error(f"injection_attempt user={auth_key} query={sql}")
        return {"success": False, "error": "SQL_INJECTION_DETECTED"}

    # 3. Execute
    try:
        conn = sqlite3.connect(DB_PATH)
        conn.row_factory = sqlite3.Row
        cursor = conn.execute(sql)
        rows = cursor.fetchall()
        data = [dict(row) for row in rows[:100]]  # Limit to 100 rows
        conn.close()

        latency = int((time.time() - start) * 1000)
        logger.info(json.dumps({
            "timestamp": datetime.now().isoformat(),
            "tool": "query_read_only_db",
            "rows": len(data),
            "latency_ms": latency,
            "success": True
        }))

        return {"success": True, "data": data, "count": len(data)}
    except Exception as e:
        logger.error(f"query_error error={str(e)}")
        return {"success": False, "error": f"QUERY_ERROR: {str(e)[:100]}"}

# MCP interface
def handle_request(request: dict) -> dict:
    """Handle MCP JSON-RPC request"""
    method = request.get("method")
    params = request.get("params", {})

    if method == "initialize":
        return {
            "jsonrpc": "2.0",
            "result": {
                "capabilities": {"tools": [], "resources": []},
                "serverInfo": {"name": "simple_db_server", "version": "0.1"}
            }
        }

    elif method == "tools/list":
        return {
            "jsonrpc": "2.0",
            "result": {
                "tools": [{
                    "name": "query_read_only_db",
                    "description": "Query read-only database. SELECT only. Requires auth_key.",
                    "inputSchema": {
                        "type": "object",
                        "properties": {
                            "sql": {"type": "string", "description": "SELECT query"},
                            "auth_key": {"type": "string", "description": "API key"}
                        },
                        "required": ["sql", "auth_key"]
                    }
                }]
            }
        }

    elif method == "tools/call":
        tool_name = params.get("name")
        tool_input = params.get("arguments", {})

        if tool_name == "query_read_only_db":
            result = query_read_only_db(
                sql=tool_input.get("sql", ""),
                auth_key=tool_input.get("auth_key", "")
            )
            return {"jsonrpc": "2.0", "result": result}

    return {"jsonrpc": "2.0", "error": {"code": -32601, "message": "Method not found"}}

if __name__ == "__main__":
    init_db()
    print(json.dumps({"type": "initialized"}), flush=True)

    # Read stdin, output stdout (stdio transport)
    for line in __import__("sys").stdin:
        request = json.loads(line)
        response = handle_request(request)
        print(json.dumps(response), flush=True)
```

### 3.2 Client-side: test_mcp_client.py

```python
# test_mcp_client.py — Simple MCP client test
import json
import subprocess
import time

def send_request(proc, method: str, params: dict = None):
    """Send JSON-RPC request to server via stdin"""
    request = {
        "jsonrpc": "2.0",
        "id": 1,
        "method": method,
        "params": params or {}
    }
    proc.stdin.write(json.dumps(request).encode() + b"\n")
    proc.stdin.flush()

    # Read response
    response_line = proc.stdout.readline().decode().strip()
    return json.loads(response_line)

# Start server
proc = subprocess.Popen(
    ["python", "simple_db_server.py"],
    stdin=subprocess.PIPE,
    stdout=subprocess.PIPE,
    stderr=subprocess.PIPE,
    text=True,
    bufsize=1
)

try:
    # Wait for init
    init_msg = proc.stdout.readline()
    print(f"Server: {init_msg}")

    # Test 1: List tools
    resp = send_request(proc, "tools/list")
    print(f"\n1. Tools available: {len(resp['result']['tools'])} tools")

    # Test 2: Valid query with auth
    resp = send_request(proc, "tools/call", {
        "name": "query_read_only_db",
        "arguments": {
            "sql": "SELECT * FROM users",
            "auth_key": "demo-key-123"
        }
    })
    print(f"2. Valid query: success={resp['result']['success']}, rows={resp['result'].get('count', 0)}")

    # Test 3: Injection attempt
    resp = send_request(proc, "tools/call", {
        "name": "query_read_only_db",
        "arguments": {
            "sql": "SELECT * FROM users; DROP TABLE users; --",
            "auth_key": "demo-key-123"
        }
    })
    print(f"3. Injection attempt blocked: error={resp['result']['error']}")

    # Test 4: Unauthorized
    resp = send_request(proc, "tools/call", {
        "name": "query_read_only_db",
        "arguments": {
            "sql": "SELECT * FROM users",
            "auth_key": "wrong-key"
        }
    })
    print(f"4. Unauthorized: error={resp['result']['error']}")

finally:
    proc.terminate()
    proc.wait()
```

**Skeleton code**:

```python
# mcp_db_server.py — Production-ready MCP server
import json, sqlite3, logging, os, hashlib, time
from datetime import datetime
from typing import Optional, List, Dict, Any
from pydantic import BaseModel, Field, ValidationError
import sqlite3

logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(name)s - %(levelname)s - %(message)s'
)
logger = logging.getLogger("mcp_db_server")

# ============ Configuration ============
DB_PATH = os.getenv("DB_PATH", "demo.db")
VALID_API_KEYS = os.getenv("API_KEYS", "sk-demo-123,sk-demo-456").split(",")
ALLOWED_TABLES = os.getenv("ALLOWED_TABLES", "public_users,public_products").split(",")
MAX_ROWS = 100
REQUEST_TIMEOUT = 10

# ============ Models ============
class QueryInput(BaseModel):
    sql: str = Field(..., min_length=1, max_length=1000, description="SELECT query")
    limit: int = Field(default=50, ge=1, le=MAX_ROWS)

class SchemaInput(BaseModel):
    table_name: str = Field(..., description="Table name")

# ============ Auth ============
def verify_api_key(api_key: str) -> bool:
    """Verify API key"""
    return api_key in VALID_API_KEYS

def verify_table_access(table_name: str, api_key: str) -> bool:
    """Check if API key can access table (basic example)"""
    # In production: look up access policy from database
    return table_name in ALLOWED_TABLES

# ============ Audit ============
class AuditLog:
    @staticmethod
    def log(user_id: str, tool: str, action: str, resource: str,
            success: bool, latency_ms: int, error: Optional[str] = None):
        log_entry = {
            "timestamp": datetime.now().isoformat(),
            "user_id": user_id,
            "tool": tool,
            "action": action,
            "resource": resource,
            "success": success,
            "latency_ms": latency_ms,
            "error": error
        }
        logger.info(json.dumps(log_entry))
        # TODO: Persist to audit DB in production

# ============ Tools ============
def query_read_only_db(sql: str, limit: int, api_key: str) -> Dict[str, Any]:
    """Query read-only database"""
    start = time.time()
    user_id = hashlib.md5(api_key.encode()).hexdigest()[:8]

    # 1. Auth
    if not verify_api_key(api_key):
        AuditLog.log(user_id, "query_db", "query", "?", False, 0, "UNAUTHORIZED")
        return {"success": False, "error": "UNAUTHORIZED"}

    # 2. Input validation
    try:
        QueryInput(sql=sql, limit=limit)
    except ValidationError as e:
        AuditLog.log(user_id, "query_db", "query", "?", False, 0, f"INVALID_INPUT: {str(e)[:50]}")
        return {"success": False, "error": f"INVALID_INPUT"}

    # 3. SQL injection check
    sql_upper = sql.upper()
    if any(keyword in sql_upper for keyword in ["INSERT", "UPDATE", "DELETE", "DROP", "ALTER"]):
        AuditLog.log(user_id, "query_db", "query", "?", False, 0, "SQL_INJECTION_DETECTED")
        return {"success": False, "error": "WRITE_NOT_ALLOWED"}

    # 4. Extract and verify table name
    table_name = extract_table_from_sql(sql)
    if not verify_table_access(table_name, api_key):
        AuditLog.log(user_id, "query_db", "query", table_name, False, 0, "TABLE_NOT_ALLOWED")
        return {"success": False, "error": f"ACCESS_DENIED: {table_name}"}

    # 5. Execute
    try:
        conn = sqlite3.connect(DB_PATH)
        conn.row_factory = sqlite3.Row
        cursor = conn.execute(f"{sql} LIMIT ?", (limit,))
        rows = cursor.fetchall()
        data = [dict(row) for row in rows]
        conn.close()

        latency = int((time.time() - start) * 1000)
        AuditLog.log(user_id, "query_db", "query", table_name, True, latency)

        return {
            "success": True,
            "data": data,
            "count": len(data),
            "limit": limit
        }
    except Exception as e:
        latency = int((time.time() - start) * 1000)
        error_msg = str(e)[:100]
        AuditLog.log(user_id, "query_db", "query", table_name or "unknown", False, latency, error_msg)
        return {"success": False, "error": f"QUERY_ERROR: {error_msg}"}

def get_schema(table_name: str, api_key: str) -> Dict[str, Any]:
    """Get table schema"""
    start = time.time()
    user_id = hashlib.md5(api_key.encode()).hexdigest()[:8]

    if not verify_api_key(api_key) or not verify_table_access(table_name, api_key):
        AuditLog.log(user_id, "get_schema", "read", table_name, False, 0, "UNAUTHORIZED")
        return {"success": False, "error": "UNAUTHORIZED"}

    try:
        conn = sqlite3.connect(DB_PATH)
        cursor = conn.execute(f"PRAGMA table_info({table_name})")
        columns = cursor.fetchall()
        conn.close()

        schema = [{"name": col[1], "type": col[2]} for col in columns]
        latency = int((time.time() - start) * 1000)
        AuditLog.log(user_id, "get_schema", "read", table_name, True, latency)

        return {"success": True, "schema": schema}
    except Exception as e:
        latency = int((time.time() - start) * 1000)
        AuditLog.log(user_id, "get_schema", "read", table_name, False, latency, str(e)[:50])
        return {"success": False, "error": str(e)[:100]}

def extract_table_from_sql(sql: str) -> Optional[str]:
    """Simple table name extraction (NOT production-safe)"""
    import re
    match = re.search(r'FROM\s+(\w+)', sql, re.IGNORECASE)
    return match.group(1) if match else None

# ============ MCP interface ============
def handle_request(request: dict) -> dict:
    method = request.get("method")
    params = request.get("params", {})

    if method == "initialize":
        return {
            "jsonrpc": "2.0",
            "result": {
                "serverInfo": {"name": "mcp_db_server", "version": "1.0"},
                "capabilities": {}
            }
        }

    elif method == "tools/list":
        api_key = request.get("_auth_token", "unknown")
        if not verify_api_key(api_key):
            return {"jsonrpc": "2.0", "error": {"code": -32001, "message": "Unauthorized"}}

        return {
            "jsonrpc": "2.0",
            "result": {
                "tools": [
                    {
                        "name": "query_read_only_db",
                        "description": "Query read-only DB. SELECT only. Requires auth.",
                        "inputSchema": QueryInput.model_json_schema()
                    },
                    {
                        "name": "get_schema",
                        "description": "Get table schema (columns, types)",
                        "inputSchema": SchemaInput.model_json_schema()
                    }
                ]
            }
        }

    elif method == "tools/call":
        api_key = request.get("_auth_token", "unknown")
        tool_name = params.get("name")
        tool_input = params.get("arguments", {})

        if tool_name == "query_read_only_db":
            result = query_read_only_db(
                sql=tool_input.get("sql", ""),
                limit=tool_input.get("limit", 50),
                api_key=api_key
            )
        elif tool_name == "get_schema":
            result = get_schema(
                table_name=tool_input.get("table_name", ""),
                api_key=api_key
            )
        else:
            result = {"error": "TOOL_NOT_FOUND"}

        return {"jsonrpc": "2.0", "result": result}

    return {"jsonrpc": "2.0", "error": {"code": -32601, "message": "Method not found"}}
```

## 6. Review (10 phút)

- 2–3 học viên trình bày tool design + security test.
- Thảo luận: khi nào dùng remote MCP vs embedded tool?
- Chốt: tool contract + auth + audit = foundation của safe agent.

### Câu hỏi kiểm tra cuối buổi

1. Vì sao tool call có 2 ranh giới security? Nêu 2 threat model ở mỗi ranh giới.
2. MCP server chạy riêng. So với embedded tool, lợi và hại gì?
3. Làm sao chắc rằng tool không bị SQL injection? (3 cách)
4. Audit log cần log những field gì? Những field nào **không** được log?
5. Tool `query_db` có auth nhưng không có authorization. Thiếu gì?

### Theo 4 câu hỏi của khóa

| Câu hỏi   | Trả lời cho Buổi 3                                                                                                       |
| --------- | ------------------------------------------------------------------------------------------------------------------------ |
| Why?      | Agent loop cần tool để tác động. Tool tốt phải có clear contract, auth, audit. MCP cô lập tool khỏi agent.               |
| How?      | Tool schema + Pydantic validation. MCP server expose tool via RPC. Auth qua header/token. Audit log who/what/when/where. |
| Failure?  | SQL injection, unauthorized call, credential leak, cross-tenant leakage, tool result injection.                          |
| Evidence? | Security test pass/fail, audit log, code review schema + auth check.                                                     |
